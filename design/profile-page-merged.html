How it works

  • Data is always visible. Each section renders read-only (label → value); nothing is an input until the user chooses to edit.
  • Edit → side drawer. The “✎ Edit” button on every section opens that section’s form in the right-side drawer — identical to Education/Experience/Projects across the app.
  • Reuses the real components. The drawer hosts the existing PersonalDetailsSection / ContactDetailsSection forms (react-hook-form + zod) inside the shared SideDrawer.
  • Save = drawer. Save/Cancel live in the drawer footer. On save it closes, the view refreshes, and the completion ring re-fetches.
  • Camera + Edit share the drawer. The avatar camera badge opens the same Personal drawer (photo lives in that form).
  • Responsive. Rail stacks on top below 980px; the drawer becomes near-full-width (94vw) on phones.
Try it → click any ✎ Edit button (or the avatar 📷). Toggle theme top-right. Mirrors src/theme/index.ts & the SideDrawer pattern.
